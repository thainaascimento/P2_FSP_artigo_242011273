# P2_FSP_artigo_242011273
Projeto acadêmico de análise das receitas, despesas e transferências intergovernamentais de Cascavel e Londrina (Brasil) e de governos locais da China, no período de 2016 a 2025. Inclui bases de dados originais e atualizadas, tratamento e documentação de variáveis, análise descritiva, estudo bibliométrico e scripts para reprodução dos resultados.
